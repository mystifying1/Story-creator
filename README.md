# AI-Powered Interactive Story Co-Writer

A full-stack multimodal storytelling platform that combines AI-generated text and visuals to enhance creative writing.

##  About the Project

This project was developed during the Infosys Springboard Internship 6.0 as part of a team.

It is an AI-powered storytelling platform designed to overcome creative challenges like writer’s block, lack of visualization, and limited personalization in existing tools.

The platform enables users to co-create stories using AI, generate visuals from text, and experience an interactive and immersive storytelling process.
